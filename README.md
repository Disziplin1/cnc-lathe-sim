# CNC 선반 G코드 연습기

G코드를 직접 작성하고 실행해서 공구경로(2D)와 깎인 소재(3D)를 확인하는 개인 학습용 시뮬레이터입니다.
Fanuc 0i-T 계열 문법을 기준으로 합니다.

## 실행

- `실행.bat` 더블클릭 → 브라우저가 열립니다.
- 또는 터미널에서 `npm install` 후 `npm run dev`

## 구조

| 폴더 | 내용 |
|---|---|
| `src/nc` | G코드 해석 (lexer → interpreter → 동작 세그먼트) |
| `src/machine` | 공구 정의와 인서트 형상 |
| `src/sim` | 소재 절삭(2D 단면 불리언 연산), 재생기 |
| `src/ui` | 코드 편집기, 2D/3D 화면 |
| `tests` | 해석기·시뮬레이터 테스트 (`npm test`) |

## 지원 코드

- 이동: G00 G01 G02 G03 G04 G28 G32
- 사이클: G90 G92 G94 / 복합 G70 G71 G72 G73 G74 G75 G76
- 보정: G41 G42 G40 (공구 보정 화면의 R·T 사용), T□□△△ 의 보정번호 X·Z
- 기타: G50 G96 G97 G98 G99, M00 M01 M03 M04 M05 M08 M09 M30, 주석 `( )`, 블록 스킵 `/`

알람: 문법 오류, F 누락, 주축 정지 중 절삭, 원호 R 오류, G00 충돌, 척 충돌,
복합 사이클 형상 오류(PS0063/64/65), 인선R보정 간섭(PS0041)

## 도면 비교

왼쪽 "도면 (목표 형상)" 탭에 완성품 외곽선을 `X0. Z0.` 부터 척 쪽으로 씁니다.
깎은 결과와 비교해서 남은 살(주황)과 과삭(빨강)을 보여 줍니다.
나사 구간과 오목한 모서리(노즈 반경 때문에 생기는 R)는 비교에서 뺍니다.

**DXF 불러오기**: CAD 도면을 ASCII DXF 로 저장해서 넣으면 중심선 위쪽 바깥 외곽선을 읽어 위 형식으로 바꿉니다.
LINE / ARC / LWPOLYLINE / POLYLINE 만 읽고 치수·문자·중심선·숨은선 레이어는 무시합니다.
축은 중심선(선 종류 CENTER 등) → 위아래 대칭이면 가운데 → 아니면 맨 아래 선 순서로 찾습니다.
블록으로 묶인 도면은 분해(EXPLODE) 후 저장하세요. 끝면이 왼쪽인 도면은 "끝면이 왼쪽"을 체크합니다.
도면이 소재보다 크면 소재를 자동으로 늘립니다 (지름: 한쪽 1mm 이상 여유 · 5mm 단위, 척 밖 길이: 도면 + 10mm). 줄이지는 않습니다.

**모범 답안**: 도면 형상으로 외경 단면 · G71 황삭 · G70 정삭(G42) 프로그램을 만들어 보여 줍니다.
내 코드는 건드리지 않고, "답안으로 시뮬레이션"으로 돌려서 가공 시간과 남은 살을 내 코드와 비교합니다.
홈(G71 기본형으로 못 깎는 오목한 곳)은 G71 · G70 에서는 메워서 지나가고, 정삭 뒤에 홈 바이트(외경 T05, 내경 T06)로 G75 를 넣습니다.
바닥이 평평한 부분만 깎고, 바이트보다 좁은 홈 · 홈 옆 모따기 · 척 쪽 끝 모따기는 남기고 주석으로 알려 줍니다.
둥근 형상(오목한 목, 공 모양처럼 척 쪽으로 내려가는 경사)은 G71 로 메운 뒤 정삭 공구로 G73(형상 반복) · G70 을 넣습니다.
정삭 공구(55°)가 따라 내려갈 수 있는 경사(약 28°)까지만 형상대로 깎고, 더 급한 곳은 그 경사로 메우고 남은 단은 홈 바이트로 깎습니다.
DXF 를 읽었는데 척 쪽 끝이 뾰족하게(축까지) 끝나면 물 수 없으므로 "끝면이 왼쪽" 을 자동으로 바꿔 줍니다.
도면 탭에 `(나사 M6 Z0. ~ Z-15.)` / `(널링 Z-32. ~ Z-92.)` 줄이 있으면 G76 나사와 널링도 넣습니다.
피치를 안 쓰면 보통나사 피치(M6 → 1.0), 가는나사는 `M20x1.5` 처럼 씁니다.
DXF 에 "M6" 같은 나사 글자나 "KNURLING" 글자 · 해치가 있으면 이 줄을 자동으로 적어 줍니다.
널링 해치는 일부만 그리는 기호이므로 해치가 있는 지름 구간 전체를 널링합니다. 틀리면 그 줄만 고치면 됩니다.

**내경(구멍)**: 도면 탭에서 `(내경)` 줄 아래에 구멍 윤곽을 끝면 쪽 가장자리부터 씁니다 (막힌 구멍은 X0. 바닥까지, 관통은 척 쪽 끝까지).
DXF 는 단면도의 실선이든 숨은선(파선)이든 구멍 윤곽을 찾아 이 부분을 적어 줍니다.
모범 답안은 드릴(G74) → 내경 황삭(G71, U 마이너스) → 내경 정삭(G70 + G41) 을 넣습니다.
드릴 지름은 설정의 드릴(기본 T11 Ø20)을 쓰고, 구멍에 맞지 않으면 알맞은 지름으로 설정을 바꾸고 답안 탭에 알려 줍니다
(보링바가 들어가면 보링 여유를 남기는 가장 큰 드릴, 보링바가 못 들어가는 곧은 구멍은 가장 가까운 표준 드릴로만).
드릴은 표준 지름(Ø13 까지 0.1 단위, 그 위는 0.5 단위)만 쓰고, 암나사 밑구멍은 탭 드릴(M6 → Ø5)을 씁니다. 바꾸면 창으로 알려 줍니다.
암나사는 `(나사 M20x1.5 Z0. ~ Z-15. 내경)` 처럼 끝에 "내경" 을 붙입니다. 구멍은 안지름(호칭 - 1.0825P)으로 그리고, 내경 나사 바이트(기본 T08)로 G76 을 넣습니다.
DXF 에서는 구멍 지름이 안지름과 맞는 곳에 M 글자가 있으면 암나사로 읽습니다.
내경 나사 바이트가 못 들어가는 작은 암나사(M6 등)는 탭 드릴로 밑구멍을 뚫고 탭(기본 T10)으로 G84 정면 탭 사이클을 넣습니다.
G84 Z(깊이) R(R점까지 Z) F(피치) : 회전당 피치만큼 들어갔다가 주축을 거꾸로 돌려 빠져나오고, G80 으로 취소합니다 (중심 X0. 에서만).
절삭 조건 계산 · 공구 간섭 검사 · 공정 순서 · 2차 가공은 만들지 않습니다 (조건은 고정값).
