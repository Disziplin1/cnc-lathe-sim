    T0303 처럼 뒤 두 자리가 보정번호입니다. X 는 직경값이라 +0.1 이면 지름이 0.1 커집니다.

      지원 코드

      G00급속 이송 (축별 독립 이동이라 경로가 꺾임)
      G01직선 절삭
      G02 / G03원호 절삭 (시계 / 반시계), R 또는 I·K
      G04일시 정지 (P: ms, X/U: 초)
      G28기계 원점 복귀 (U0. W0.)
      G32나사 절삭 (F = 리드)
      G41 / G42 / G40인선R보정 왼쪽 / 오른쪽 / 취소 (외경은 G42, 내경은 G41)
      G50S: 최고 회전수 제한 / X Z: 좌표계 설정
      G70정삭 사이클: G70 P(시작 N) Q(끝 N)
      G71내·외경 황삭: G71 U(절입) R(도피) ; G71 P Q U(X여유) W(Z여유) F
      G72단면 황삭: G72 W(절입) R(도피) ; G72 P Q U W F
      G73형상 반복: G73 U(X도피) W(Z도피) R(횟수) ; G73 P Q U W F
      G74단면 펙 (드릴): G74 R(후퇴) ; G74 X Z P(X이동,µm) Q(Z절입,µm) F
      G75외경 홈 펙: G75 R(후퇴) ; G75 X Z P(X절입,µm) Q(Z이동,µm) F
      G76복합 나사: G76 P(정삭횟수·모따기·각도) Q(최소절입,µm) R(정삭여유) ;
      G76 X(골지름) Z R(테이퍼) P(산높이,µm) Q(첫절입,µm) F(리드)
      G90내·외경 절삭 사이클 (R: 테이퍼)
      G92나사 절삭 사이클
      G94단면 절삭 사이클
      G96 / G97주속 일정 (m/min) / 회전수 일정 (rpm)
      G98 / G99분당 이송 / 회전당 이송
      M00 / M01프로그램 정지 / 선택 정지
      M03 / M04 / M05주축 정회전 / 역회전 / 정지
      M08 / M09절삭유 ON / OFF
      M30프로그램 끝
      T□□△△공구번호 + 보정번호 (예: T0303)
      ( )주석, / 는 블록 스킵

      G71/G72 는 단조 형상(Type I)만 지원합니다. 도면 탭: 첫 줄 X0. Z0. 부터 척 쪽으로 외곽선을 G01/G02/G03 형식으로 씁니다.
